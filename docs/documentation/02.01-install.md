---
id: usage-install
title: Install
---

Start by installing `react-color` via npm:

```
npm install react-color --save
```

Then import either the aggregate stylesheet or only the picker styles you actually render:

```
import 'react-color/es/styles/index.css'
```

```
import 'react-color/es/styles/pickers/sketch.css'
import 'react-color/es/styles/common/editable-input.css'
```
