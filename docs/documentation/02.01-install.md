---
id: usage-install
title: Install
---

Start by installing `react-color` via npm:

```
npm install react-color --save
```

Picker entrypoints now import their own published CSS automatically, so for normal usage nothing else is required:

```
import { SketchPicker } from 'react-color'
```

The published CSS entrypoints are still available when you want the full stylesheet up front or when you build custom pickers from the shared primitives:

```
import 'react-color/es/styles/pickers/sketch.css'
import 'react-color/es/styles/common/editable-input.css'
```
